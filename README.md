# 启星程 · 网站设计 Skills

本仓库可作为启星程校服品牌官网的 Codex 项目工作区。本次已在仓库中安装 **项目级 Agent Skills 文件**，不等于安装到你手机 ChatGPT 或 Windows 上的全局 Codex 配置。进入此仓库的 Codex 工作区后可尝试自动触发。

## 已加入
| Skill | 版本 | 作用 |
| --- | --- | --- |
| `frontend-design` | Anthropic 官方 SKILL.md + LICENSE | 高端网站视觉方向 |
| `ui-ux-pro-max` | MIT 原始参考文档的精简离线适配，不含 CLI/数据库 | 配色排版、UX 审查 |
| `framer-motion-core`、`react`、`variants`、`scroll`、`gestures`、`layout` | C-Jeril 开源原始 SKILL.md | React 动画 / 滚动 / 页面切换 |
| `web-design-guidelines` | 自编离线规则 | 响应式、可访问性、交互检查 |

请参阅 `docs/INSTALL_CODEX.md`、`docs/SECURITY_AND_SOURCES.md`。

**注意**：公开仓库里不要提交客户私密资料、账号密钥、未经授权的模特照片或个人英语学习数据。

网站视觉要求：启星程蓝绿白品牌色；保留校服原始胸前校徽和店铺商标的区别；大幅真实模特图；高级留白；产品面料、拉链、袖口、徽标细节可放大；轻量滚动动效并支持手机。
