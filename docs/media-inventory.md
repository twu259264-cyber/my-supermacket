## V3 SVG 检查结论

24 个 `.svg` 都是用 SVG 容器包裹 PNG 或 WebP 位图，并非可无限放大的矢量原稿。网页使用时必须按内嵌位图的真实像素限制显示，不能因为后缀是 SVG 就放大。媒体脚本会先提取内嵌位图，再生成响应式副本；直接把容器交给图像转换器曾产生尺寸正常但透明的 WebP，现已由像素可见性浏览器测试防止回归。

## 网页输出规则

- 产品完整图使用 `contain` 展示，保留衣领、袖口和裤脚。
- 产品与细节图输出 WebP，生成宽度不超过原图；透明边缘保持 alpha。
- 校园概念图可按版式裁切，但保留人物脸部和主要服装区域。
- 完整海报和尺码原图始终按原比例放大查看。
- 非首屏图片使用按需加载；首屏图使用响应式尺寸和高优先级。
- 所有图片说明区分“启星程品牌 Logo”“校服胸前校徽”和“风采文体门店”。
