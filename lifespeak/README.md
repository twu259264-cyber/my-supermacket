# LifeSpeak 学习进度看板

直接打开网站即可查看学习进度，无需登录、Excel导入、浏览器缓存或后端。网站公开展示用户授权的学习概况。

## 当前内容

- 累计学习时长、当前课程、最近一次文字练习正确率。
- 已学内容、薄弱点、晚间听说安排与覆盖核对。
- 最近学习记录及第37—48课学习计划。

截至2026-11-17，数据取自最新《英语学习_长期计划与记录.xlsx》，累计2299分钟（38小时19分钟），第38课文字完成100分钟，首答33/41，口语待练。历史累计口径和待核对差异保留说明。

## 更新流程

在聊天中完成学习并更新主表后，读取最新主表，统一更新本目录index.html的学习快照，提交至main。现有GitHub Pages工作流自动复制lifespeak目录并发布。页面标出数据截止日期；不会自动读取ChatGPT文件或在网页录入学习结果。

## 技术

单个静态HTML文件，无外部脚本、云数据库或第三方字体。独立目录保留原业务网站。旧版交互学习面板在Git历史中保留；不再依赖它的localStorage或导入/恢复功能。
