# LifeSpeak

独立的生活英语学习面板，不修改仓库原有业务网站。

## 使用

打开 index.html 或由静态服务器托管 lifespeak 目录，导入最新《英语学习_长期计划与记录.xlsx》。Excel 解析使用 SheetJS 0.20.3（cdn.sheetjs.com），首次加载需要网络。学习表只在浏览器内解析；不发送至服务器。朗读依赖浏览器/系统语音服务，可能使用其网络语音功能。

- 今日课程与累计记录：从原表读取，不预填虚假完成状态。
- 晚间听说：按最新文字练习日期或对应周筛选全部条目，逐条朗读、查看答案并手动标记听辨与开口；保留每条原始ID。
- 固定15分钟计时，到时停止计时并提示保存，剩余内容保留待补。
- 补充短文与3道逐题阅读理解，回答留存，参考答案自查，不自动计入学习表或评分。
- 词句库、预习信息和历史记录可搜索。
- JSON导出和恢复用于手动跨设备迁移。恢复前自动导出当前数据。

## 数据边界

没有账户、云同步、AI自动评分或Excel写回。localStorage仅属于当前浏览器与网站域名，清理浏览器可能丢失，请备份。网页计时单独记录，不自动加到Excel累计分钟，避免重复。

不要将个人Excel或JSON备份提交至此公开仓库。
