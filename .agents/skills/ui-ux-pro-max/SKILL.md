# UI UX Pro Max — curated text-only edition

This is an openly attributed, **partial offline adaptation** for Codex, not the complete UI UX Pro Max CLI bundle. No Python search scripts, large style databases or automatic design-system generator are installed here. The complete edition must be installed separately using its official CLI (see docs/INSTALL_CODEX.md).

## Working steps
1. Understand project audience and brand, real product images, pages, target devices and required calls to action.
2. Consult `references/quick-reference.md` only as relevant, applying accessibility, responsive layout, typography, color and animation standards.
3. Use `references/pro-rules.md` for professional finishing and pre-delivery checks.
4. For the Qixingcheng school uniform website, prioritize high-end editorial layouts, real navy/light-blue/green product photography, verified logos, real garment details, responsive Chinese text and restrained scroll animations.
5. Make key interactive elements usable with keyboard and touch, offer reduced-motion, and test real product zoom, filtering and inquiries.
6. Report what was verified and what still requires browser testing; do not claim a static image is an implemented site.
